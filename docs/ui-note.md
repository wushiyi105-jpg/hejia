# UI 说明：核价

- **谁在什么时刻打开**：给第一次装修的业主。
- **首屏任务句**：这份报价，哪些钱不该花。
- **主操作**：按「贴两家报价 → 对齐工序复算 → 生成询价问题单」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：工程审价单；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：工程审价单。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给第一次装修的业主：把两家报价按工序、面积和计量单位对齐，复算金额，挑出重复项、合同外项目和待问项。
